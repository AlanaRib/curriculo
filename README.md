# Currículo — Alana Cristina de Moraes Ribeiro

Currículo profissional desenvolvido em HTML, CSS e JavaScript, com foco em apresentar minha trajetória acadêmica, experiência profissional e conhecimentos na área de tecnologia.

## 🌐 Acesso

O projeto é compatível com GitHub Pages. Para publicar, selecione a branch `main` e a pasta raiz (`/`) nas configurações de Pages do repositório. O GitHub exibirá o endereço após a publicação.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 🧩 Sobre o projeto

Este projeto consiste em uma versão web do meu currículo profissional.

A página foi desenvolvida do zero, utilizando HTML, CSS e JavaScript, buscando combinar uma apresentação profissional com uma identidade visual própria.

O projeto também utiliza recursos de interação para tornar a navegação mais dinâmica, mantendo uma interface limpa e objetiva.

## 📌 Conteúdo

O currículo apresenta:

- Experiência profissional
- Formação acadêmica e cursos
- Stack profissional
- Tecnologias e ferramentas utilizadas
- Informações de contato
- Links profissionais

## Desenvolvimento local

Abra a pasta no VS Code e inicie o Live Server a partir de `index.html`. Não há instalação de dependências nem etapa de build.

## Recursos

- Português e inglês; a página sempre inicia em português, sem salvar a seleção.
- Experiências expansíveis com controles nativos do HTML.
- Indicador de rolagem que encerra a animação ao alcançar o destino e respeita movimento reduzido.
- Telefone clicável e links para GitHub e LinkedIn.
- Estilos de impressão A4: use o comando de imprimir do navegador para salvar como PDF. As experiências são abertas durante a impressão e restauradas em seguida.

## Manutenção

- Conteúdo e estrutura: `index.html`.
- Aparência, responsividade e impressão: `CSS/style.css`.
- Traduções e interações: `JS/app.js`.

Ao editar textos em português, mantenha o HTML e o dicionário `pt` consistentes. Atualize também a tradução `en` e a data de revisão quando necessário.
